HOSTINGER SETUP
1. hPanel > Databases > create a MySQL database + user. Copy the names and password.
2. Edit admin/config.php with those 3 values.
3. File Manager > public_html > upload everything (index.html + admin folder).
4. Visit yourdomain.com/admin/install.php, choose username and password. It creates all tables.
5. DELETE admin/install.php, then log in at yourdomain.com/admin/
